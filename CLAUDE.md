# CourtSim: notes for Claude

Adaptive courtroom training sim (Unity 2022.3 LTS, Built-in RP). The trainee judge rules on bail, then
evidence admissibility, then sentencing, assisted by an AI that is sometimes deliberately wrong.

- Read `docs/ARCHITECTURE.md` before structural changes and `docs/STYLE_GUIDE.md` before writing C#.
- Engine-independent logic goes in `Assets/Scripts/Core` (no UnityEngine) with tests in `Assets/Tests/EditMode`.
  Verify with the `verify-core` skill (`tools/verify-core.ps1`); the coverage gate is 80%.
- One MonoBehaviour/ScriptableObject per file, file named after the class.
- No `?.`/`??` on UnityEngine.Object. Explicit `!= null` only.
- UI is generated in code: use `UIFactory` + `UITheme`; never hard-code colours in screens.
- The courtroom is data (`CourtroomLayout`); the scene is regenerated by **CourtSim → Generate CourtRoom Scene**.
- Reference repos are a separate checkout (`arvrel/sources/`, not in this repo) and are **reference-only**
  unless `NOTICES.md` says otherwise. Check licenses before adapting anything, and record it in `NOTICES.md`.
- Unity-side code is verified headless with the `unity-batch` skill (`tools/unity.ps1`). Run it after any
  change under `Assets/`. Only report Unity code as working once it passes there. If an interactive Editor
  has the project open, batch mode can't run: say so rather than claiming verification.
- Case files (`Assets/Resources/Cases`, `docs/CASE_FORMAT.md`) are ground truth for scoring. Validate every
  change with `CaseFileReader`; tests load each case in `TestCases.ShippedCaseIds`. Game logic picks flaws; the model only writes wording.
- Default advisor is a local Ollama model (`qwen3.5:9b` with `num_ctx` 4096; `qwen3.5:0.8b` for small GPUs; no key; `docs/AI_ADVISOR.md`); Claude is optional. Offline authored advice is always the fallback.
- Adaptive difficulty is `Core/Adaptive/AdaptiveController.cs` (rules in `docs/ARCHITECTURE.md`). The plan still decides *which* points are flawed; the controller only picks the flaw kind and the explanation detail.
- Never commit API keys or place them under `Assets/`. Keys come from `ANTHROPIC_API_KEY` or `ApiKeyLocator`'s key file.
- MCP for Unity (`.mcp.json`) works only while the Editor GUI has the project open, which blocks batch mode.
  Close the Editor before `tools/unity.ps1`; if MCP tools fail, say the Editor isn't open.
- `CourtRoom.unity` is generated. Regenerate it (`tools/unity.ps1 -Task scene`) instead of hand-editing it, and commit it.
- Git: short-lived `feature/*` branches, Conventional Commits, squash fix-ups, update `CHANGELOG.md`.
