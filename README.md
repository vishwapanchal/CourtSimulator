# CourtSim

An adaptive courtroom simulation for training legal decision-making with AI assistance.
The trainee presides as judge and makes three rulings (**bail**, **admissibility of evidence** and
**sentencing**) while an AI assistant offers advice that is sometimes deliberately wrong. Later phases
log every ruling and adapt case difficulty to the trainee's performance.

> **Status: Phase 1, environment preview.** A navigable courtroom, the full UI system and the
> decision flow run on placeholder content. Case data, the Claude-powered assistant and decision
> logging arrive in Phases 2–3. See `CHANGELOG.md`.

## Requirements

- **Unity 2022.3 LTS** (project file pins 2022.3.62f1; any newer 2022.3 patch works, and the latest
  patch is recommended). Built-in render pipeline.
- Optional, to run core tests without Unity: **.NET SDK 8.0+**.

## Quick start

1. Open `app/CourtSim` in Unity Hub (**Add → Add project from disk**). The first import generates
   `Library/` and the `.meta` files. Commit the `.meta` files.
2. When prompted, click **Generate**, or run **CourtSim → Generate CourtRoom Scene** at any time.
   This writes `Assets/Scenes/CourtRoom.unity` and adds it to the build settings.
3. Open the scene and press **Play**.

| Action | Keys |
| --- | --- |
| Move / walk faster | `W A S D` / hold `Shift` |
| Look | Mouse |
| Interact with the bench, evidence display or AI console | `E` |
| Toggle the AI assistant panel | `Tab` |
| Pause / back | `Esc` |

Walk through the gate in the bar. Look at the **judge's bench** and press `E` to make each ruling in
turn, or examine the **evidence display** on the left wall.

Core line coverage currently stands at **95%**.

## Repository layout

```
Assets/
  Scripts/Core/      CourtSim.Core: pure C#, no UnityEngine (events, layout, decisions, math)
  Scripts/Runtime/   CourtSim.Runtime: bootstrap, courtroom builder, player, interaction, UI
  Scripts/Editor/    CourtSim.Editor: scene generator, material assets
  Tests/EditMode/    Core unit tests (also run by tools/verify-core.ps1)
  Tests/PlayMode/    Runtime integration tests
  Scenes/ Materials/ Generated by CourtSim → Generate CourtRoom Scene
docs/                Architecture, style guide, Phase 0 audit
tools/               Out-of-Unity verification (dotnet build, format, test, coverage)
```

Read `docs/ARCHITECTURE.md` for how the pieces fit, and `CONTRIBUTING.md` before making changes.
